# gsto

Workflow tools for working with Claude Code.

**`/gsto:scout`** — Research and present options before any plan or implementation. At the start of a non-trivial task — a design decision, a new feature, a tool choice, a piece of writing — it goes and finds out how the thing is actually done, then comes back with 2–4 real options, the concrete tradeoff for each, anything surprising it turned up, the questions it needs answered, and a recommendation with a confidence level. It does not plan or implement until you've picked an option.

It exists to interrupt the instinct to start issuing instructions before anyone has checked how the problem is usually solved.
